Where we are

Prototype 0 checklist
    In plain words

    The pipeline is built: your four routes become points every 250 m, each point gets its weather-model cell and its terrain from a 30 m elevation map, and an index ranks the points by how likely wind is to have dropped snow there.

    The research question, does terrain plus weather beat the simple "lee side of the wind" rule?, is still unanswered. Answering it needs observations that say "loaded" or "scoured" at a place and time. There are none yet.

    What I need from you
    1. On your next trips, one line per notable slope: where, when, and whether wind added snow (pillowy, slab, fresh cornice) or stripped it (hard, rippled, rock showing). Use templates/field_observation.toml, or just write the sentence and I will convert it.
    2. Nothing else is blocking. All three regions now have weather data and real model cells.

    What I think and why

    Each finding says what I believe, the evidence, how sure I am, and what would change my mind. All are exploratory.

    Run it yourself

    The same views, live from your own database, with buttons to run each step:

    uv sync --group app
uv run streamlit run app/streamlit_app.py

    Or step by step on the command line:

    uv run mountain routes load
uv run mountain weather cells
uv run mountain weather backfill
uv run mountain terrain compute
uv run mountain exposure run --route north_victoria --as-of 2026-11-09T18:00
